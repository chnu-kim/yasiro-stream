# 후보 파일 형식 (`work/picks/batchN.json`)

`build_page.py`가 이 파일 하나에서 결과 페이지와 ops를 만든다. 시각은 **초 정수 또는 `"h:mm:ss"`**만 쓴다(`"4:26"` 같은 두 칸은 거부).

```json
{
  "pageTitle": "하이라이트 후보 2차",
  "heading": "2차 묶음 판정 결과",
  "lede": "(선택) 머리말. 비우면 기본 문구",
  "games": [
    {
      "gameId": "godok",
      "videoId": "WZfhdQ2A9Tg",
      "name": "고독방송",
      "genre": "공포",
      "segment": ["3:53:00", "9:45:00"],
      "note": "스트리머 '윤나'가 되어 폐병원에서 방송하는 공포 게임이에요. 게임 클립 10개를 모두 오디오로 맞췄어요.",
      "ask": "(선택) 확정 전, 사용자에게 무엇을 골라 달라는지",
      "decision": null,
      "candidates": [
        {
          "label": "1위 제안",
          "start": "7:37:20",
          "title": "깜짝 놀라 넘어지는 장면",
          "clip": { "title": "야평", "readCount": 835, "aligned": "strong" },
          "flags": ["선정적일 수 있음"],
          "lines": [
            { "t": "7:37:23", "text": "\"굿굿 켜! 가자.\"" },
            { "t": "7:37:31", "text": "\"깜짝이야!\"", "key": true }
          ],
          "why": "놀람, 넘어짐, 투덜거림이 한 흐름이에요."
        }
      ],
      "footnote": "(선택) 후보 아래에 붙는 설명"
    }
  ]
}
```

| 칸 | 뜻 |
|---|---|
| `pageTitle` | 브라우저 탭·목록에 보이는 이름. 2~4낱말 |
| `gameId`, `videoId` | **운영 조회에 있는 값 그대로.** 확정한 게임은 운영에 없으면 오류 |
| `name`, `genre` | 화면에 보이는 게임 이름과 장르 |
| `segment` | (선택) 게임 구간. 주면 후보가 구간 밖일 때 알려 준다 |
| `note` | 어떤 게임인지, 클립 상황 한두 문장 |
| `decision` | 사용자가 확정한 후보 번호(1부터). 고르기 전에는 `null`. Claude가 미리 채우지 않는다 |
| `candidates[].label` | 칩 글자. 비우면 "N위". 사용자가 직접 정한 시각은 "직접 정함" |
| `candidates[].start` | 재생을 시작할 시각. 링크·ops가 여기서 나온다 |
| `candidates[].title` | 무슨 장면인지 한 줄(필수). 이름만 쓰지 말고 상황을 쓴다 |
| `candidates[].clip` | (선택) 겹치는 치지직 클립. `aligned`: `strong`(상관 0.9 이상·1.5배 이상) · `ok`(대사로 재확인함) · `estimate`(위치 추정) |
| `candidates[].flags` | (선택) 사용자가 판단할 표시. 예: "선정적일 수 있음", "영상으로 확인 필요" |
| `candidates[].lines` | 시각별 대사·상황. `key: true`는 핵심 순간(펀치라인·비명). 첫 핵심까지의 초가 '핵심까지 N초'로 계산돼 붙는다 |
| `candidates[].why` | 고른 이유(필수). 약점도 적는다(예: "비명은 자막에 잡히지 않아 영상으로 확인해야 해요") |

`build_page.py`가 하는 검사:

- 오류(파일을 쓰지 않음): 시각 형식, 같은 게임 중복, 후보·`title`·`why` 없음, 확정한 게임의 id·영상이 운영 조회에 없음, `protected.json`과 다른 확정, 확정이 있는데 `--ops` 없음
- 주의(파일은 씀): 핵심까지 60초 초과, 핵심이 시작보다 앞, 게임 구간 밖, 운영에 그 게임의 다른 영상 하이라이트가 있음, 사용자 지정 게임인데 확정이 빔
- ops에는 확정한 게임 중 운영 값과 달라지는 것만 들어간다(`{"op":"highlight","id":…,"url":…,"start":"h:mm:ss"}`)

글투: 페이지는 사용자가 읽는다. 해요체로, 대사는 받아쓰기를 다듬어 따옴표 안에 쓴다. 받아쓰기가 틀린 낱말은 고쳐 쓰되 없는 대사를 지어내지 않는다.
